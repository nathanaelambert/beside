# Image notes

These images explore Beside's visual direction. Their scenery, layouts, labels, and generated details are illustrative rather than settled product requirements. Read the [concept brief](../product/concept-brief.md) and [storyboard](storyboard.md) for their product context.

## Mobile UI concept

- File: [mobile-ui-concept-v1.png](mobile-ui-concept-v1.png).
- Created: September 22, 2026, using the built-in image generation tool.
- Purpose: explore three portrait mobile states—returning to a shared space, discovering a milestone-linked note, and placing a decoration—in a consistent pixel-art garden with readable conventional controls.
- Status: exploratory concept art, not an implemented interface or final design specification.

The draft establishes readable sheets over a consistent cozy world. The placement frame overlaps or replaces an existing pink tree instead of clearly adding another tree; a future iteration should preserve existing decorations and leave more empty placement space. The ornate garden and large header may also need simplifying to give meaningful activity objects more room.

This is the canonical copy of the image previously named `mobile-storyboard-v1.png`, `app-concept.png`, and `ChatGPT Image Sep 22, 2026, 06_26_35 PM.png`; those files contained the same image.

## Shared world illustration

- File: [shared-world.png](../../apps/website/public/assets/shared-world.png).
- Created: October 6, 2026, using the built-in image generation tool.
- Purpose: a reusable pixel-art garden courtyard with two friends, a cottage, reading and exercise objects, mature trees, lanterns, and keepsake scenery, with transparency around the world footprint.
- Use: the showcase website animates a camera across this illustration and adds interactive overlays.

The scene conveys atmosphere and provides a consistent visual stage. It does not define the final world layout, object catalog, avatar system, or production app interface. The illustration remains in the website's public assets so it can be served directly at `/assets/shared-world.png`.
