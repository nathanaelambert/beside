# Playground design

Collaborators use the workbench on laptops in ordinary daylight while talking through an experiment. A light canvas keeps diagrams, forms, and record tables readable.

- Full palette with named meanings: moss for subjects, ochre for activities, blue for logs, rose for events. Each color always accompanies a label or icon.
- Warm neutral canvas, lightly tinted panel surfaces, dark olive text, restrained borders. No decorative gradients.
- Readable sans for the app, monospace for record IDs, code, and model details. Compact headings and generous line height.
- A persistent top bar with perspective selector. Open on a directory of boxes grouped into understanding the model, trying actions, and inspecting results. Each destination has a breadcrumb back to the directory. Activities and logging open separately; creation forms and raw record tables use progressive disclosure. Collapse columns on smaller screens.
- Rounded controls, inline forms, expandable record details. Cards represent actual activities or subjects; record collections use tables or rows.
- Brief transitions for state changes only. Reduced-motion users receive immediate feedback.
